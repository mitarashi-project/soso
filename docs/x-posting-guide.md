# Xの投稿方法（共有用）

更新日：2026-09-10

SoEmeの投稿担当向けに、本文と画像を準備してXで公開し、結果を確認するまでの手順をまとめます。制作方針・画像プロンプト・過去の操作実績は[既存の制作手順](./soeme-x-creative-workflow.md)を参照してください。

## 1. 本文と画像を準備する

- AI最新情報は公式発表を確認し、本文に出典URLを入れる。発表日や利用条件も確認する。
- 本文は「何ができるか → 具体的な使い道 → 出典」を短くまとめる。
- 投稿画像は緑を基調に統一する。黒・深緑の背景、エメラルド／ライム、白系の文字、署名SoEmeが基本。
- 見出しは短く、主役は大きくする。生成画像は実際に開き、誤字・可読性・本文との一致を確認する。
- 架空のビジュアルは実際の製品画面や性能検証結果として扱わず、必要に応じ「コンセプト画像」と明記する。

## 2. Xで投稿する

1. [X](https://x.com/)を開き、ログイン中のプロフィールとユーザー名が投稿対象であることを確認する。
2. 「ポストする」または投稿作成欄を開く。
3. 完成した本文を入力する。文字数超過やリンクの抜けを投稿画面で確認する。
4. 写真・動画の追加ボタンから、準備したファイルを選択する。
5. 添付のプレビューを確認する。「Preparing media...」などの処理中表示が消えるまで待つ。
6. 本文、画像の順番、添付の取り違え、投稿先を確認し、「ポストする」を押す。
7. プロフィールから新しい投稿を開き、公開された本文と画像を確認する。
8. 投稿のURLを取得し、実際に確認できた結果を記録する。

基本操作の出典：[X公式ヘルプ「ポストする方法」](https://help.x.com/ja/using-x/how-to-post)。ボタン名は表示言語や画面の更新で変わるため、その時点の画面で確認する。

## 3. ブラウザ操作を引き継ぐときの注意

以下は既存の制作手順に記録された操作実績です。今回、新たなX投稿テストは行っていません。

- 過去に投稿できたのはアプリ内ブラウザ。別のブラウザや別のbotでもログイン済みとは限らない。
- 操作の前後に現在の画面を読み直す。前の画面の要素番号を流用しない。
- ファイル選択イベントを待ち受けてから、実際のファイル入力欄をクリックし、画像を渡す。
- 「Add photos or video」でファイル選択イベントを取得できない場面では、「Choose File／ファイル選択」欄で成功した記録がある。現在の画面で該当する入力欄を確認する。
- 添付の処理完了とプレビューを確認してから送信する。
- エラーやタイムアウトで結果が不明な場合、再送の前にプロフィールを確認する。既に投稿されていれば再送しない。
- 投稿し直した場合も、旧投稿の削除まで完了したとは扱わない。削除は依頼された範囲で行う。

## 4. 予約・毎日の自動投稿の状態

既存資料の記録では、日本時間11:30に準備し12:00に投稿する運用は計画段階です。準備用の定期実行は停止中、Buffer連携・予約投稿の検証は未完了です。この手順書を保存しただけで定期投稿が開始することはありません。

定期運用を再開する際は、実際の設定と予約結果を確認し、[Xの自動化ルール](https://help.x.com/en/rules-and-policies/x-automation)および利用サービスの現行条件を確認してください。

## 5. 投稿後の記録テンプレート

```text
投稿日時（日本時間）：
投稿先（公開ユーザー名）：
投稿URL：
テーマ：
公式出典URL：
使用画像：
公開確認：本文／画像を確認済み、または未確認の理由
```

共有リポジトリには公開してよい情報だけを保存します。パスワード、Cookie、APIキー、トークン、認証画面のURLは記載しません。
