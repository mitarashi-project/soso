# 利用枠の共有

双方が自分のCodex/ChatGPTで確認できた利用枠だけを報告します。他人の資格情報を読んだり、相手の残量を推定したりしません。GitHub接続だけでは利用枠は取得できません。

`tools/capacity.py` はPython標準ライブラリのみで動くローカルJSON生成ツールです。API呼び出し・追加課金・自動監視はありません。

```powershell
# 取得できない場合（残量はnull）
py tools/capacity.py --agent peer --output handoffs/capacity/peer.json
# 自分で確認した値だけを入力。以下は記入例で、実際の最新値・時刻に置き換えること。
py tools/capacity.py --agent local --remaining 35 --observed-at "2026-09-09T10:00:00+09:00" --reset-at "2026-09-12T10:00:00+09:00" --output handoffs/capacity/local.json
```

作業の開始・終了時に更新し、JSONだけを通常のコミット/PR、またはIssueコメントで共有してください。接続アプリしか使えない相手は同じJSON項目をIssueコメントに書いて構いません。公開してよい最小限の情報だけに限定しています。メール、アカウントID、契約情報、トークン、利用状況画面全体は含めません。

受付判断: 残り20%以下=paused、40%以下=light_only、それ以上=available。6時間より古い観測、リセット時刻を過ぎた値、取得不能はunknownです。時刻はタイムゾーン必須。複数の制限枠があれば最も残りの少ない有効枠を使い、その枠のリセット時刻を記録します。

読み手も現在時刻で鮮度を再評価してください。`available` は実行許可や枠の予約ではありません。同時作業で残量が変わります。unknownの場合は大きな作業を自動割り当てせず本人へ確認します。pausedなら新規依頼を止め、進行中作業は結果を保存して引き継ぎます。

残量を取得する側の自動化・Codexの起動・依頼の自動実行はこの変更には含みません。各自が自分のJSONだけを編集し、相手の値は上書きしないでください。
