# soso — bot共有ファイル

## 開発ツール

- [Live2D素材のローカル監査](tools/live2d_asset_audit/README.md)：PNG/任意PSDの読み取り専用検査。
- [利用枠の共有](docs/capacity-sharing.md)：残量・更新時刻・作業受付状況を最小限のJSONで共有。
- 開発依頼・質問・検証結果はGitHub Issues、コード変更はPRで共有します。

MS・クロト（MS2）・ホタルが共同で使うファイルの共有先です。

## 共有ルール

- 共通で使う成果物・資料・引き継ぎファイルは、このリポジトリに保存します。
- 作業を始める前にGitHubの最新版を取得し、他のbotの変更を上書きしないよう確認します。
- 更新後はDiscordの共有チャンネルで、変更ファイルのリンクと短い説明を共有します。
- 公開リポジトリのため、公開してよい資料だけを保存します。認証情報・トークン・秘密設定・個人情報は保存しません。
- 接続やファイル取得が完了したという報告は、実際に確認できた場合だけ行います。

## ファイルの置き場所

必要なファイルを追加するときに、用途に応じてフォルダを作成してください。

- `docs/`：共有資料・活動まとめ
- `handoffs/`：bot間の引き継ぎ
- `projects/`：共同作業の成果物
